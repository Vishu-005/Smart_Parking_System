Smart Parking System with IoT, OCR & Piezoelectric Energy Harvesting

An intelligent IoT-based Smart Parking System designed to improve parking management through real-time slot monitoring, online booking, vehicle identification, automated gate control, and sustainable energy harvesting.

The system integrates ESP32, IR sensors, OCR/image processing, Flask, PostgreSQL, and servo-based gate automation into a unified smart parking platform.

Project Overview

Traditional parking systems often require users to manually search for available spaces and rely on human intervention for vehicle verification. This project addresses these challenges by providing real-time parking availability, online slot booking, automated vehicle verification, and intelligent gate access.

The system also incorporates piezoelectric energy harvesting, where mechanical pressure generated by vehicles is converted into electrical energy and stored as auxiliary backup power.

Key Features
🔹 Real-time parking slot detection using ESP32 + IR sensors
🔹 Web-based parking slot availability monitoring
🔹 Online parking slot booking
🔹 Vehicle number extraction using OCR/image processing
🔹 Verification of extracted vehicle numbers against active bookings
🔹 Automated gate access using ESP32 + SG90 servo motor
🔹 Admin dashboard for monitoring parking activity
🔹 PostgreSQL database for storing users, bookings, and parking data
🔹 REST API communication between ESP32 and Flask backend
🔹 Piezoelectric energy harvesting for auxiliary backup power

ESP32 Slot Sensor Connections
Parking Slot	ESP32 Pin
Slot 1	D4 / GPIO 4
Slot 2	RX2 / GPIO 16
Slot 3	TX2 / GPIO 17
Slot 4	D18 / GPIO 18
Slot 5	D19 / GPIO 19
Slot 6	D21 / GPIO 21
Gate Servo	D23 / GPIO 23

Note: GPIO 16 and GPIO 17 are used as general-purpose GPIOs in this implementation, despite their board labels RX2 and TX2.

System Workflow
1. Parking Slot Detection

IR sensors continuously monitor the six parking slots.

Vehicle Present → Slot Occupied
No Vehicle → Slot Available

The ESP32 sends the slot status to the Flask backend through Wi-Fi.

2. Parking Booking

The user accesses the web application and:

Logs into the system
Views available slots
Selects a parking slot
Provides vehicle details
Confirms the booking

The booking information is stored in PostgreSQL.

3. Vehicle Identification

When a booked vehicle approaches the parking entrance:

Camera
   ↓
Image Capture
   ↓
Backend Upload
   ↓
Image Preprocessing
   ↓
OCR
   ↓
Vehicle Number

The extracted vehicle number is cleaned and compared with active booking records.

4. Automated Gate Control

If the extracted vehicle number matches an active booking:

OCR Vehicle Number
        ↓
Active Booking Database
        ↓
       MATCH
        ↓
Backend Gate Status
        ↓
ESP32
        ↓
Servo Motor
        ↓
Gate Opens

If there is no matching booking, access is denied.

5. Piezoelectric Energy Harvesting

Mechanical pressure produced by vehicles is applied to piezoelectric elements.

Vehicle Pressure
       ↓
Piezoelectric Element
       ↓
Electrical Energy
       ↓
Rectification / Regulation
       ↓
Energy Storage
       ↓
Auxiliary Backup Power
